# JOUW DRIVER — نسخة محسّنة للأمان والخصوصية

هذه نسخة مستقلة من المشروع المرفق، مع الحفاظ على صفحات ومكوّنات التطبيق وإضافة حماية على الخادم. الأصل لم يُعدّل. هذه نسخة للمراجعة والتجربة على بيئة اختبار، وليست شهادة امتثال أو نسخة منشورة للإنتاج.

ابدأ بقراءة `SECURITY_REVIEW_AR.md` ثم `SECURE_SETUP_AR.md`.

- `src/`: التطبيق كاملاً بعد التعديلات.
- `.env.example`: الإعدادات المطلوبة دون مفاتيح فعلية.
- `migrations/20261009_security.sql`: تحديث إضافي لقاعدة البيانات.
- `scripts/migrate-secrets.mjs`: تشفير أسرار Chiron الحالية، وضع المعاينة افتراضي.
- `scripts/preflight.mjs`: فحص إعدادات النشر دون طباعة قيم الأسرار.
- `tests/`: اختبارات سياسة الأمان والتشفير واختبارات HTTP.
- `security/verification/`: نتائج التحقق والفحص الأمني للمكتبات.
- `security/route-inventory.json`: جرد مسارات الخادم.
- `legacy-docs/`: إرشادات النسخة الأصلية للمرجعية فقط؛ دليل الإعداد الجديد هو المعتمد لهذه النسخة.

## التشغيل

Node.js 22.18+ أو 24، وpnpm 11.25.0:

```bash
pnpm install --frozen-lockfile
pnpm test:security
pnpm typecheck
pnpm build
pnpm dev
```

الإنتاج يحتاج قاعدة بيانات معدّلة وإعدادات حقيقية. `pnpm test:http-security` يشغّل خادماً محلياً بقيم اختبار وهمية ولا يتصل بقاعدة الإنتاج.

## الوظائف التي تغيّرت

تم إيقاف Google login، المساعد الآلي، الروابط العامة للفواتير والتوقيع، إرسال الفواتير عبر مكتبة Zoer، اختبار قبول Chiron الذي يرفع ملفات خارجياً، والوكيل القديم. مدير الشركة يستخدم بوابته الخاصة؛ المسارات الإدارية العامة محصورة بمعرّفات الإدارة المعيّنة على الخادم. بعض الوظائف غير المراجعة، مثل التسجيل الذاتي للسائق وردود الرسائل للسائق والتعديلات الواسعة للموزعين، محصورة بالإدارة مؤقتاً. بوابة السائق تستخدم الآن IndexedDB مشفّراً لحفظ الرحلة النشطة وطابور الرحلات غير المرسلة حسب حساب السائق. تتم المزامنة عند عودة الاتصال، مع مفتاح يمنع تكرار الحفظ على الخادم. النسخة المستضافة تحتاج الإنترنت عند فتحها من الصفر؛ تتبع الهاتف في الخلفية يحتاج اختباراً عملياً وسجلّاً أصلياً مستقلاً قبل اعتماده. لا تمسح بيانات الجهاز قبل مزامنة الرحلات.

## الهاتف وقاعدة البيانات

- `mobile/README_AR.md`: إعداد iOS وAndroid وحدود العمل دون اتصال والخلفية.
- `docs/DATABASE_IMPORT_AR.md`: تحويل JSON إلى SQL في قاعدة اختبار مستقلة، دون رفع البيانات إلى GitHub.
- `docs/SECURITY_ACCEPTANCE_AR.md`: الاختبارات وحدود القبول.
- `.github/workflows/ci.yml`: اختبارات Next.js والمصادقة وPostgreSQL/PostgREST ببيانات اصطناعية.
- `.github/workflows/release.yml`: فحوص كاملة ثم صورة GHCR محددة بالـcommit والـdigest.
- `.github/workflows/deploy.yml`: نشر يدوي على بيئة محمية بواسطة SSH مثبت الهوية؛ نسخ مشفرة ثم ترحيلات ثم فحص الإقلاع وHTTPS.
- `docs/OPERATIONS_AR.md`: تجهيز خادم الشركة، أسرار البيئات، النشر والتعافي.

المصادر متاحة في المستودع؛ بيانات المستخدمين والأسرار ومفاتيح التوقيع تبقى خارجه.
