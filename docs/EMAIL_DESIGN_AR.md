# قوالب البريد في JOUW DRIVER

تولّد `src/lib/email/renderer.ts` نسختي HTML والنص العادي من بيانات منظمة. تستخدم قوالب الإنتاج والمعاينة والإرسال التجريبي المحرّك نفسه. يدير `src/lib/mail-service.ts` الحجز ومنع التكرار وسجل التسليم والنقل عبر Brevo أو Resend. تبقى مفاتيح الأحداث وسياسات الإرسال الحالية كما كانت.

| القالب | المسار الحالي | اللغة |
| --- | --- | --- |
| `register` و`company-registration` و`reset-password` | `/next_api/auth/send-verification` | اللغة المختارة في الطلب ثم لغة الموقع المحفوظة ثم لغة المتصفح والإنجليزية افتراضياً |
| `account-email` | طلب رمز تغيير البريد في `/next_api/auth/account` | لغة الموقع أو المتصفح ثم الإنجليزية |
| `contract-invitation` | إرسال دعوة لصاحب الشركة من مسار العقود | لغة العقد ثم الفرنسية |
| `contract-confirmation` | نجاح التوقيع عبر الدعوة ثم تأكيد للمالك والمرسل المسجل | لغة العقد ثم الفرنسية |
| `invoice` | فواتير الإدارة والاشتراك يدوياً وآلياً، ومنها الفاتورة الأولى حين تحين حسب الجدولة الحالية | لغة مستلم المستند ثم الفرنسية |
| `credit-note` | الطابور الحالي أو إرسال إشعار دائن صادر | لغة مستلم المستند ثم الفرنسية |
| `invoice-reminder` | الطابور الحالي | لغة مستلم المستند ثم الفرنسية |
| `trip-receipt` | إرسال اختياري من السائق مع PDF الصادر | لغة المستند أو اللغة المختارة ثم الفرنسية |
| `driver-report` | معاينة وإرسال اختبار فقط | اللغة المختارة في الإدارة |

معالج Stripe يتعامل مع تأكيد الدفع في سجل النظام. لم نجد مسار بريد نشطاً لتأكيد الدفع منفصلاً، أو للترحيب، أو دعوة السائق، أو التذكير بنهاية العقد، أو إرسال كشف حساب السائق والورديات. لم تتغير هذه التدفقات. بريد المساعد الذكي القديم محجوب في `disabledEndpoint`، وتبقى تجربة تشخيص Brevo في Sandbox عبر GitHub Actions منفصلة عن بريد العملاء.

الاستعادة وتأكيد الحساب يستخدمان رمزاً صالحاً لثلاث دقائق. دعوة توقيع العقد تحتفظ برابطها الموقّع ومدتها. تأكيد التوقيع يعرض بيانات الإثبات ورابط بوابة الشركة. ترفق الفواتير والإيصالات ملفات PDF الأصلية. يظهر زر Stripe عند وجود رابط ودين مستحق حسب منطق الفاتورة، وتظهر تعليمات التحويل عند وجود QR حقيقي في المرفق. عناوين الرسائل المالية الإضافية تحفظ رقم الفاتورة والعنوان الأساسي.

## إدارة القوالب

افتح `/admin/email-templates` بحساب إدارة المنصة. يمكن عرض لغات الرسالة الأربع وHTML والنص العادي ومعاينة عرض الهاتف والكمبيوتر. يمكن تغيير بادئة الموضوع والنص الافتتاحي للفواتير والتذكيرات والإشعارات الدائنة، أو إضافة توقيع لهذه اللغة. تحفظ كل مراجعة بهوية المسؤول والوقت والنص السابق والجديد في `email_template_audit`. رسائل الحساب والعقد تحتفظ بنصوصها وتوقيعها الأساسي.

يرسل الاختبار إلى بريد حساب الإدارة، أو إلى عنوان اختبار معتمد في متغير الخادم الاختياري `MAIL_TEMPLATE_TEST_RECIPIENTS` بقائمة مفصولة بفواصل. يستخدم الإرسال ملف PDF اصطناعياً موسوماً DEMO، وروابط الشراء والتوقيع للعرض فقط. يطبق الاختبار الحصة الحالية ومفتاح الإرسال لمنع تكرار الطلب، ويعرض حالة التسليم التي سجّلها المزود.

## النشر والتراجع

يتحقق سير النشر المخصص من النسخة المبنية وقاعدة اختبار PostgreSQL ونسخة احتياطية مشفرة. يطبق `20261114_email_templates.sql` وفق نطاق محدد. يختبر بعدها وجود GIF وPNG على نطاق التطبيق ورفض المعاينة لغير المصادق. عند تعذر التحقق، يعاد تشغيل إصدار التطبيق السابق. يمكن إبقاء الجداول والسجلات الجديدة بعد التراجع لأنها إضافة مستقلة ويظل الإصدار السابق قادراً على إرسال البريد. لا تحذف سجلات الحجز أو المراجعة عند الرجوع.

يستخدم رأس الرسائل شعار PNG على نطاق التطبيق ضمن خلفية خلية HTML. يتجاوز هذا مسار إعادة كتابة وسم الصورة الذي استُخدم مع GIF في Brevo. تستخدم إصدارات Outlook التي تدعم تعليقات MSO وسم الصورة بداخل التعليق، ويبقى اسم JOUW DRIVER مقروءاً عند حجب الصور. راجع نتائج SPF وDKIM وDMARC في رؤوس البريد المستلم فعلياً لأن نطاق الويب قد يختلف عن نطاق المرسل.
