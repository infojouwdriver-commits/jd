# الموقع التسويقي السينمائي

النطاق هو الصفحة التسويقية وSEO فقط. لا تعديل لتطبيقات iOS/Android أو واجهات
السائق والإدارة أو SQL أو Stripe أو Chiron أو قواعد احتساب الاشتراك.

## البنية

- `PlatformLanding.tsx`: الأقسام والنموذج وروابط البوابات الموجودة.
- `cinematic/copy.ts`: النصوص العربية والفرنسية والهولندية، بما فيها الأسئلة.
- `Cinema.tsx`: النص القابل للفهرسة، وضع تقليل الحركة والتحكم بالتجربة.
- `engine.ts`: Three.js وكاميرا واحدة وGSAP ScrollTrigger؛ تمرير واحد قابل للعكس.
- `models.ts`: سيارة ASTER أصلية بأسطح منحنية، عجلات مفصلة، هاتف، مقصورة وطابعة.
- `public/cinematic/ASSETS.md`: أصل المجسمات وشروط الاستخدام والمكتبات.
- `/fr` و`/nl` و`/ar`: صفحات HTML مترجمة، canonical وhreflang وOG وFAQ/Organization.

## الحركة والأداء

يبدأ المشهد بالهاتف ثم تشغيل الوردية، دخول السيارة ودوران العجلات، ضوء TAXI،
انتقال الهاتف إلى المقصورة، عرض العداد وإنهاء الرحلة، ثم الطابعة وإخراج الورق
وQR محلي. يعود الهاتف أخيراً لعرض الإيصال الرقمي وخيار البريد بشكل توضيحي.
لا تنفذ المشاهد أي رحلة أو طباعة أو بريد فعلي، ولا تعد بدعم Bluetooth.

المحرك يُحمّل ديناميكياً. تُدمج المجسمات الثابتة بحسب الخامة لتقليل draw calls.
DPR محدود بـ1.25 للأجهزة الصغيرة/ضعيفة الأنوية و1.75 لبقية الأجهزة. تعقيد
العجلات أقل على الهاتف، والظلال معطلة في النمط الخفيف. الرسم مرتبط بالتغيير
فقط، ويتوقف خارج الشاشة وفي الخلفية. التنظيف يشمل الهندسة والخامات والأنسجة
والمحرك وScrollTrigger. تقليل الحركة/فشل WebGL يعرض صورة مرسومة من المشهد
ونصوص HTML كاملة؛ التسجيل متاح مباشرة في الشريط العلوي.

## التحقق والنشر

تشغّل `cinematic-acceptance.yml` نسخة إنتاجية في Chromium حقيقي، مع صور
وفيديو للمشاهد واختبار الرجوع، واللغات الثلاث على 320/390/768/1440، والنموذج
وFAQ وSEO وبديل WebGL. الصور ونتيجة كل حالة محفوظة في artifact.

`publish-cinematic-marketing.yml` يستخدم بنية النشر الموجودة: يتحقق من نطاق
الملفات والنسخة الحية المحددة، ثم فحوص المشروع والمتصفح وعزل النطاق، ويبني
صورة Docker غير قابلة للتغيير مع بوابة app.jouww.com. لا ينفذ ترحيلات SQL.
النسخ الاحتياطي وخطة الاسترجاع وحفظ إعدادات البيئة مطلوبة قبل تبديل الصورة.
تُضاف فقط مسارات اللغات و`/cinematic/*` إلى المسموح على المضيف التسويقي؛
لا تغيير لـDNS أو TLS أو مسارات المصادقة أو حظر API العام.

المالك طلب لاحقاً رؤية النتيجة على الموقع الحي، ولذلك صار النشر بعد نجاح
الفحوص ضمن التفويض. لا يُعد نجاح البناء وحده دليلاً على اكتمال القبول البصري.
