# JOUW DRIVER — تطبيق سائق مستقل

دفعة أولى React Native / Expo بمكونات أصلية. لا يستعمل WebView ولا يحمّل واجهة البوابة عن بعد. المشروع السابق في `mobile` يبقى مستقلاً ولا يُستبدل أثناء هذه الدفعة.

## ما نُفذ

- الدخول بالبريد أو الهاتف وكلمة المرور عبر عقود الخادم الحالية، واستعادة ملف السائق.
- شاشة عربية أصلية تعرض الشركة والسائق، وخريطة Mapbox أصلية ومراقبة موقع أمامية بإذن المستخدم. يُوقف watcher عند إزالة الشاشة؛ لا يرسل هذا الإصدار نقاط الأسطول إلى الخادم.
- جلسة عبر مخزن cookies الأصلي وHttpOnly دون حفظ كلمة المرور أو إخراج رموز الجلسة. طلبات HTTPS محصورة بأصل المشروع، وترفض إعادة التوجيه، وتحد زمن الطلب. تدوير refresh مرة واحدة للقراءات المتزامنة؛ لا تعاد mutation تلقائياً. يجب إثبات عقد cookies وتدويرها على النظامين قبل اعتماد الدخول.
- مشاريع native قابلة للتوليد ومسار CI Android وiOS simulator. نسخة Android التجريبية release-bundled تستعمل توقيع debug المولّد فقط؛ لا تعتبر توقيع متجر. نسخة simulator لا تثبّت على iPhone الحقيقي.

## التشغيل

`npm ci` ثم `npm run typecheck` و`npm test`. ضع Mapbox **public** token في `.env` محلية باسم `EXPO_PUBLIC_MAPBOX_ACCESS_TOKEN`؛ لا تستخدم secret token. مسار CI يستخدم قيمة `MAPBOX_PUBLIC_TOKEN` الموجودة دون عرضها.

`npm run prebuild` ثم `npm run android` ببيئة SDK/JDK مناسبة؛ و`npm run ios` على macOS/Xcode. Mapbox يحتاج development/native build ولا يعمل داخل Expo Go. لا حاجة لخدمة بناء مدفوعة؛ مسار GitHub عام بأذونات قراءة فقط وتخزين مؤقت محدود.

## ما لم يُسلّم بعد

محرك الرحلة والعداد، حفظ رحلة مشفر دون إنترنت، مزامنة الرحلات وChiron، تتبع خلفي وأساطيل، الرسائل والفواتير. لا توجد أزرار تعرض هذه الوظائف على أنها جاهزة. نجاح بوابة الويب الذي أكده المستخدم لا يثبت قبول هذا التطبيق المستقل.

قبل التسليم: نجاح تجميع Android وiOS الأصليين، تحقق الدخول والتجديد والخروج بهاتفين، Mapbox واللغة ولوحة المفاتيح، ثم تنفيذ واختبار محرك الرحلة. التوزيع على iPhone فعلي يحتاج Apple Team وتوقيع؛ النشر في المتاجر يحتاج حسابات المطور، ولم تبدأ اشتراكات أو خدمات مدفوعة.
